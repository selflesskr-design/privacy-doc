## 2026-08-02에 한 일

### 검토 후 보완

- **오프라인 PDF 자산 누락 수정.** PDF.js의 CMap(`.bcmap`)과 표준 글꼴
  (`.pfb`, `.ttf`) 182개를 서비스 워커 사전 캐시에 포함했습니다. 처음 보는
  한글·CID 글꼴 PDF도 첫 접속 이후 오프라인에서 필요한 보조 파일을 찾을 수 있습니다.
- **사진 정보가 없다고 잘못 단정하던 흐름 수정.** JPEG의 여러 APP1 영역을 끝까지
  검사하고 PNG·WebP의 EXIF·XMP·텍스트·색상 프로필 컨테이너도 감지합니다.
  표시할 위치·기기 정보를 찾지 못해도 사진 정보 지우기 버튼을 항상 제공하며,
  검사 범위 밖의 정보가 있을 수 있음을 화면에 밝힙니다.
- **취소 버튼이 실제 처리를 멈추도록 수정.** 공통 작업 훅이 취소 신호를 만들고,
  사진 용량·크기 변경과 PDF 사진 변환·용량 줄이기에 전달합니다. PDF.js의 진행 중인
  페이지 렌더링을 취소하고 반복 작업도 다음 단계로 넘어가지 않습니다.
- **사용하지 않는 Docker 배포 지원 제거.** 실제 배포는 Vercel만 사용하므로
  Dockerfile·Compose·Nginx 설정과 README 실행 안내를 삭제했습니다. 유지되지 않던
  Nginx의 SPA fallback이 없는 주소를 HTTP 200으로 응답할 가능성도 함께 없앴습니다.
- **검색엔진용 도구 본문의 오래된 링크 수정.** 프리렌더된 17개 도구 페이지에서
  삭제된 `/security` 링크를 `/privacy`로 바꾸고, `도구 24가지`라는 고정 문구는
  레지스트리의 실제 도구 개수를 자동으로 표시하도록 변경했습니다.
- **같은 기능의 검색 URL 통합.** PDF 합치기·PDF 용량 줄이기·사진 위치정보
  확인·삭제의 실제 작업 화면은 `noindex, follow`로 두고 각각의 자세한 설명 페이지를
  canonical로 지정했습니다. 작업 화면은 그대로 사용되지만 검색 신호와 사이트맵은
  설명 페이지 한 곳에 모입니다.
- **모바일 메뉴 접근성 개선.** 메뉴를 열면 초점이 메뉴 안으로 이동하고 `Esc`·닫기
  버튼·바깥 영역으로 닫을 수 있게 했습니다. 메뉴 안에서 키보드 초점이 순환하고,
  닫은 뒤에는 원래 메뉴 버튼으로 돌아갑니다. 메뉴 이름과 열림 상태를 화면 읽기
  기능에 전달하고 상단 메뉴·테마 버튼의 터치 영역도 키웠습니다.
- **남은 영어와 어색한 한국어 문구 정리.** 화면 읽기 기능의 `Filter tools`, 파일
  이동·삭제·받기 안내와 메뉴의 `Image` 분류를 한국어로 바꿨습니다. 브랜드·PDF·JPEG
  같은 고유 명칭은 유지했습니다. 사진 용량과 크기를 혼동하기 쉬운 설명, 어색한
  조사와 문장 끝맺음도 함께 다듬었습니다.
- **설치·공유 브랜드를 `Privacy`로 통일.** PWA 설치 이름, iPhone 홈 화면 이름,
  SNS·카카오톡 공유 이미지, 기본 ZIP 파일명과 저장소 문서에서 남은 `PrivacyDoc`을
  정리했습니다. 기존 사용자의 테마·메뉴 설정과 오프라인 캐시가 초기화되지 않도록
  내부 저장 키와 캐시 이름은 호환용으로 유지했습니다. 공유 서비스의 기존 이미지
  캐시를 피하도록 OG 이미지 주소에도 버전을 붙였습니다.

### 도구 정리 — 24개에서 17개로

**없앤 7개.** 이름값을 못 하거나 이 서비스와 무관해서입니다. 코드와 URL 모두
제거했습니다.

| 도구 | 없앤 이유 |
|---|---|
| 워드→PDF · 마크다운→PDF · HTML→PDF | 표준 글꼴이 한글을 인코딩하지 못해 **처음부터 한글 문서에서 동작하지 않았음**. 워드·한글·구글문서 모두 자체 PDF 저장이 있고 그쪽이 정확함 |
| PDF 서식 채우기 | 국내 서식은 HWP이거나 인쇄용 평면 PDF라 채울 입력란이 거의 없음 |
| PDF를 워드로 | 글자만 뽑아 .docx로 감싼 것. 표·이미지·서식이 사라져 이름값을 못 함 |
| 글자 가져오기 | 동작은 했으나 PDF 그룹을 쪽 번호 넣기에서 끝내기로 함 |
| 사진 색 반전 | 서류를 제출 전에 다듬는 일과 접점이 없음 |

**새로 만든 것 — 사진 개인정보 가리기.** 서비스의 핵심 기능이 PDF에만 있었는데,
실제로 사람들이 내는 건 신분증·통장을 찍은 사진입니다. PDF 가리기와 같은 방식
(픽셀에 칠하고 재인코딩)이고, 캔버스를 거치며 EXIF도 함께 사라집니다.

### 찾아 고친 결함 중 큰 것

- **한글 글자가 저장한 PDF에서 조용히 사라짐.** `@pdf-lib/fontkit`의 서브셋
  생성기가 일부 글리프를 빈 외곽선으로 써넣었습니다. 글자는 파일에 정상 기록되고
  복사도 되는데 화면에만 안 보여서, 제출한 뒤에야 드러납니다
- **PDF 개인정보 가리기에서 저장 후 추가한 영역이 빠진 파일이 내려감.**
  가리기 도구에서는 개인정보가 새는 것과 같습니다. 배포된 상태였습니다
- **세로로 찍은 사진이 눕던 문제** (EXIF 방향 무시). 사진 정보 삭제는 방향 태그만
  지워서 결과가 더 눕고 있었습니다
- **드롭한 파일이 중복되거나 사라짐.** 상자 안에 놓으면 두 번 처리되고, 상자 밖에
  놓으면 첫 장만 들어갔습니다. 도구 23개 공통이었습니다
- **Dropzone이 `accept`를 드롭에 적용하지 않음.** PDF 도구에 이미지를 떨어뜨려도
  그대로 들어가 알 수 없는 오류를 냈습니다

### 사이트 정리

- 브랜드 `PrivacyDoc` → **`Privacy`** (주소 privacy.selfless.kr와 맞춤)
- `/how-it-works`, `/security` 삭제 — 홈 데모와 도구 안내가 이미 같은 말을 함
- `/open-source-licenses` → `/about` (소개 + 라이선스, 301 리다이렉트)
- FAQ·개인정보처리방침을 푸터에 노출 — **처리방침에 닿을 길이 없었음**
- 없는 주소가 홈을 200으로 반환하던 것을 **진짜 404**로
- 페이지 간 링크 정리 — 가이드끼리 서로를 가리키던 카드 제거

### 수익화 준비

GA4를 넣었습니다. CSP는 **구글 애널리틱스 두 호스트만** 열었고 나머지 목적지는
여전히 차단입니다. 구글이 준 인라인 스크립트 대신 `public/ga.js`로 빼서
`unsafe-inline`은 넣지 않았습니다.

개인정보처리방침을 사실에 맞게 고쳤습니다 — `분석 도구를 쓰지 않습니다`를 지우고
무엇이 구글로 가고 무엇이 안 가는지 적었습니다.

### 검토 대상

- **애드센스.** 통계가 쌓인 뒤가 심사에 유리합니다. 붙이면 추적 쿠키가 생기므로
  개인정보처리방침을 한 번 더 고쳐야 합니다
- **오해하기 쉬운 도구에 설명 그림.** 홈의 가리기 전/후 그림이 잘 통합니다.
  후보는 PDF 편집(사각형을 덮어도 글자가 남는다), 용량 줄이기(사진으로 바꾸면
  글자를 못 고른다), 사진 정보 삭제(사진에 위치가 숨어 있다). 이름만으로 결과가
  뻔한 도구에는 넣지 않는 편이 낫습니다
- **한글 글꼴 경량화.** 지금은 서브셋을 껐기 때문에 한글이 든 PDF마다 1.2MB가
  붙습니다. 빌드 시점에 자주 쓰는 한글 2350자로 미리 줄인 글꼴을 만들어 두면
  정확성을 지키면서 500KB 수준으로 낮출 수 있습니다

  "파일이 안 나간다"는 장점이 "느려서 못 쓴다"가 됩니다. 이름이 좁은 것은 지금
  단점이 아니라 장점입니다
- **의존성 정기 업데이트.** dependabot의 정기 PR은 껐습니다. 메이저 업그레이드는
  이사 작업이고, 보안 경고만 켜두면 충분합니다

## 알아둘 함정

새 도구를 만들거나 고칠 때 [tool-ui-rules.md](tool-ui-rules.md)를 먼저 읽으세요.
도구마다 반복해서 나온 것들입니다.

1. 설정이 바뀌면 만들어둔 결과를 버릴 것 — 안 그러면 화면과 다른 파일을 내려줍니다
2. 버튼은 한 번에 하나만 — 만들기 또는 받기
3. 화면 문구는 한국어로, `strings.js`에 모을 것

여기에 더해:

- **PDF에 한글을 써넣으면 1.2MB가 붙습니다.** 짧은 표기는 숫자·기호로 우회하세요
- **사진을 다루면 EXIF 방향을 적용하세요.** `lib/imageCanvas.js`의 `decode()`를
  쓰거나 `imageOrientation: 'from-image'`를 넘기면 됩니다
- **전후 용량 비교는 용량이 목적인 도구에만.** 평범한 재저장이 노란 경고로
  읽힙니다
